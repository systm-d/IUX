# iux_flutter

`iux_flutter` is the primary Flutter package for IUX (Intuitive UX).

It is experimental and currently exposes only package metadata used to verify
local package integration. It does not yet provide final user-interface
components, semantic tokens, or themes.

## Use

```dart
import 'package:iux_flutter/iux_flutter.dart';
```

Read the repository [PROJECT_PROMPT](../../PROJECT_PROMPT.md) before proposing
or implementing an API.
